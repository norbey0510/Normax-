# Normax

Aplicación de ventas de productos NORMAX.

## Objetivo
Crear una aplicación para Android que permita mostrar y vender nuestros productos de aseo y limpieza.

## Funciones principales
- Catálogo de productos
- Promociones por cantidad de compra
- Pagos mediante QR
- Envíos a nivel nacional
- Compras contra entrega según la región
- Registro de clientes
- Sistema de crédito para clientes autorizados
